# Notebook organization

- `01_foundations/`: data, embeddings, activations, probes, and initial sanity checks.
- `02_attention_and_ablation/`: attention patterns, head ablations, and newline-specific behavioral analyses.
- `03_final_attention_geometry/`: final-layer query/key geometry and single-example attention analysis.
- `04_representation_manifold/`: activation trajectories, phase/spline models, PCA interventions, and line-number/phase decompositions.
- `05_layer1_mechanisms/`: activation trajectories through layer-1 attention and separate layer-1 head ablations.

The numbered prefixes preserve the original notebook chronology while the folders group related analyses.
