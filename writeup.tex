\begin{abstract}
This project studies how a small Transformer learns a simple but structured
sequence-processing task: inserting line breaks into a stream of tokens so
that each line respects a character-length budget.  The task is deliberately
synthetic, which makes the underlying rule completely known and provides a
controlled setting for studying what computations emerge inside the model.
This document summarizes the current model, data generator, and training
procedure, as well as the present direction of the project.
\end{abstract}

\section{Motivation and connection to prior work}

This project was directly inspired by Anthropic's study of line breaking in
\emph{When Models Manipulate Manifolds: The Geometry of a Counting Task}
\cite{gurnee2026manipulate}.  That work investigates how Claude 3.5 Haiku
predicts line breaks in fixed-width text, even though the model receives text
as a sequence of tokens rather than as an explicitly rendered visual layout.
The authors find evidence that the model internally represents character
counts using low-dimensional, curved manifolds.  These manifolds are further
organized by sparse feature families, reminiscent of place-cell-like coding:
different features become active in different regions of the underlying count
space.

The paper describes line breaking as a sequence of geometric computations.
Token lengths are accumulated into a representation of the current character
count; attention heads then transform, or ``twist,'' this representation to
estimate the distance to the line boundary.  Finally, the relevant estimates
are arranged so that the newline decision can be made with a comparatively
simple linear separation in activation space.  Causal interventions support
the functional role of these representations and computations, and the paper
also constructs visual illusions in which carefully chosen character
sequences interfere with the model's counting mechanism.

The goal here is to test how much of this structure arises from the task
itself.  Rather than analyzing a large pretrained language model with broad
linguistic and visual-text experience, this project trains a small Transformer
from scratch on a synthetic line-breaking task.  The model sees no natural
language and is optimized only to predict the output of the wrapping rule
described below.  This creates a deliberately stripped-down setting in which
any count-like manifolds, phase-like trajectories, or attention-based boundary
computations can be attributed more directly to the demands of the task.  The
main question is therefore not whether this toy model reproduces every detail
of Anthropic's findings, but whether similar representational and geometric
motifs emerge when the model has to learn the same abstract computation with
minimal prior structure.

\section{Overview}

The central task is next-token prediction on sequences that contain ordinary
tokens and a special newline token.  Each ordinary token represents a piece
of text with a known character length.  Given a randomly generated stream of
ordinary tokens and a line-length constraint, the data generator inserts
newlines according to a deterministic wrapping procedure.  The Transformer is
then asked to predict the resulting token sequence one position at a time.

Although the surface task is small, it combines several ingredients that are
useful for mechanistic analysis: the model must keep track of an accumulated
quantity (the number of characters on the current line), recognize when a
threshold has been reached, and emit a special token at the appropriate
position.  The project therefore uses the trained model as both a predictor
and an object of study.  The repository contains experiments probing token
representations, attention patterns, residual-stream geometry, and the effect
of activation interventions.

\section{Model architecture}

The model is a causal, decoder-only Transformer implemented with
\texttt{TransformerLens}.  It receives a sequence of token IDs and produces a
logit vector over the vocabulary at every position.  Because the model is
causal, the prediction at position $t$ can depend only on the tokens at
positions up to and including $t$; this matches the online nature of line
wrapping.

The current baseline has three Transformer layers and four attention heads per
layer.  The residual stream has width $d_{\mathrm{model}}=128$, each attention
head has dimension $d_{\mathrm{head}}=32$, and the feed-forward sublayer has
width $d_{\mathrm{MLP}}=512$.  The activation function is GELU, layer
normalization is used, and standard learned positional embeddings provide
position information.  The vocabulary contains 82 tokens, including a
beginning-of-sequence token (BOS) and a dedicated newline token.  The remaining
80 tokens are divided evenly among eight token-length categories, corresponding
to character lengths from 1 through 8.

In a standard Transformer block, attention allows each position to aggregate
information from earlier positions, while the MLP sublayer applies a
position-wise nonlinear transformation.  For this task, these components give
the model several possible ways to represent the current line state and to
convert that state into a newline decision.  The project does not impose an
explicit counter or a hand-designed newline circuit; these quantities must be
learned from the training examples.

\section{Synthetic data generation}

Each example is generated independently and on the fly.  First, the generator
samples a sequence of ordinary token IDs uniformly from the non-special part
of the vocabulary.  A BOS token is prepended.  It then samples one integer line
length uniformly for the whole example.  In the current baseline, this line
length is sampled from the inclusive range 50--100, so different examples can
require different wrapping thresholds.

To construct the target sequence, the generator scans the token stream from
left to right while maintaining the number of characters on the current line.
When the current line has reached the sampled limit before the next token is
processed, the generator inserts the newline token immediately before that
token and resets the line counter.  The character contribution of a token is
determined by its token-length category.  Thus, the newline position depends on
both the token history and the example-specific line-length condition.

The resulting sequence is cropped to the configured context length after
wrapping.  The model input consists of the first $L$ tokens and the target at
position $t$ is the following token, giving the usual shifted next-token
prediction setup:
\[
    x_t = s_t, \qquad y_t = s_{t+1}, \qquad t=1,\ldots,L.
\]
The current context length is $L=150$.  Batches are generated during training
rather than drawn from a fixed corpus, which makes it inexpensive to vary the
line-length range and avoids memorization of a finite set of sequences.

For evaluation, a separate batch is generated using a fixed random seed.  This
does not make the task deterministic during training, but it does make metric
comparisons across checkpoints and training runs more reproducible.

\section{Training objective and procedure}

The model is trained with standard categorical cross-entropy over every
position and every vocabulary item.  If $z_{t,v}$ denotes the logit for
vocabulary item $v$ at position $t$, the loss for a batch is
\[
    \mathcal{L}
    = -\frac{1}{BL}\sum_{b=1}^{B}\sum_{t=1}^{L}
      \log p_\theta\!\left(y_{b,t}\mid x_{b,\leq t}\right),
\]
where $B$ is the batch size.  Newline prediction is therefore learned as part
of the same full-vocabulary language-modeling objective; it is not currently
treated as a separate binary classification problem.

The baseline uses batches of 256 sequences and trains for 10,000 optimization
steps.  Parameters are updated with AdamW using learning rate $10^{-3}$,
weight decay $0.01$, and momentum parameters $(\beta_1,\beta_2)=(0.9,0.95)$.
The learning rate is warmed up for 500 steps and then decayed approximately
cosine-wise to $10^{-4}$.  Gradients are clipped to have maximum global norm
1.0.  The configured random seed is recorded with each experiment, and the
training script saves configuration files and periodic checkpoints.

Performance is monitored with overall next-token accuracy and loss.  Because
overall accuracy can obscure the behavior of a relatively infrequent special
token, the evaluation code also reports newline-specific metrics, including
accuracy when the target is a newline and accuracy when it is not.  These
metrics provide a more direct view of whether the model has learned the
line-breaking rule rather than merely modeling the ordinary-token majority.

The models in Table~\ref{tab:activation-approximations} have different
interpretations. The clean model is the original Transformer, with no
activation replacement, and therefore serves as the behavioral reference.
Global 3D PCA is not a learned predictor of the trajectory: each true
activation is projected onto the first three global PCA directions and then
reconstructed. It tests how much information is retained by a generic
low-dimensional subspace. The phase-only spline model predicts the activation
from normalized within-line phase, while phase plus one line vector adds a
single learned direction whose coefficient depends on the example's line
index. Separate line offsets instead gives each line index its own learned
offset, allowing a richer line-dependent component. The unconstrained phase
plus line model uses the same phase features and one line-dependent direction
without requiring the two components to be orthogonal. Finally, the
orthogonal phase plus line model imposes that the phase coefficient subspace
has zero inner product with the line-number direction; this is the direct
test of an approximately separable line component and phase manifold.
The random 3D subspace baseline uses the same projection-and-reconstruction
procedure as global PCA, but replaces the PCA directions with an independently
sampled orthonormal basis. It therefore measures the reconstruction and
behavior obtained from an arbitrary three-dimensional subspace.

Notebook 26 tests a more specific version of the trajectory hypothesis. Let
$h(c,\ell,k)$ denote the activation before the final attention layer at
character count $c$, line-length constraint $\ell$, and current line index
$k$. We fit models of the form
\[
 h(c,\ell,k) \approx \mu + f(\text{phase}(c,\ell)) + g(k),
\]
where the phase term is represented by cubic B-spline features. The key
constrained model uses a single line-number direction $v$ and projects every
phase coefficient into the orthogonal complement of $v$:
\[
 h(c,\ell,k) \approx \mu + v k + W z(\text{phase}(c,\ell)),
 \qquad W^{\mathsf T}v=0.
\]

On held-out data, the unconstrained phase-plus-one-line model achieved MSE
$1.685$ and variance reduction $65.1\%$. The constrained orthogonal model
achieved MSE $1.761$ and variance reduction $63.6\%$; its fitted line/phase
dot product was $6.2\times 10^{-4}$. The small cost of enforcing
orthogonality supports an approximately separable phase--line description,
while the stronger separate-line-offset model shows that line number is not
fully captured by one shared direction.

As an additional control, we generated 20 independent orthonormal random
three-dimensional subspaces. Each held-out activation was mean-centered,
projected into one such subspace, and reconstructed by projecting back and
adding the mean. These random subspaces retained only $2.3\%\pm1.0\%$ of the
activation variance, compared with $88.4\%$ for the PCA reconstruction. Their
newline behavior was correspondingly unstable: the mean newline precision was
$0.350\pm0.393$ and recall was $0.211\pm0.348$, with 9 of 20 trials producing
no newline predictions at all. This provides a useful null baseline: the
behavior of the learned phase/line models is not explained merely by replacing
the activation with an arbitrary three-dimensional projection.

The phase coefficient matrix is strongly low-rank: its first two singular
directions explain $94.8\%$ of the fitted phase variance. This supports the
qualitative picture of a two-dimensional curved or rotating phase manifold,
but does not establish that the curve is circular or literally a spiral.

Taken together, these results support a compact but not complete description
of the activation: normalized within-line phase supplies the main curved
trajectory, while line index supplies an additional approximately separable
offset. The success of the learned models, their near-orthogonality, and the
large gap from random subspaces provide evidence for genuine structure rather
than a visualization artifact. The residual error and the loss of newline
precision under activation replacement show that phase and line index do not
yet constitute a sufficient statistic for the full next-token computation;
line-width-dependent and token- or history-dependent information remains.

The results above concern the structure of the activation that is already
present before the final attention computation.  In particular, they ask how
well that activation can be reconstructed from low-dimensional phase and
line-dependent coordinates, without yet explaining which earlier components
write those coordinates into the residual stream.  The next section begins
that causal account by examining the attention heads in the preceding layers.

\section{How earlier attention heads construct the activations}

The activation-trajectory analysis identifies a compact object to explain:
the residual stream immediately before layer 2 attention.  Notebook 28 begins
to localize its construction by intervening on the outputs of the four heads
in layer 1.  The notebook uses the head-output tensor
\texttt{blocks.1.attn.hook\_z}; at each token position, a zero ablation
replaces the selected head's output vector with the zero vector while leaving
the other layer-1 heads and the rest of the model unchanged.  The resulting
forward pass is evaluated on 500 independently generated sequences.  The
newline metrics are computed from the model's next-token predictions, and the
intervention's effect on the downstream representation is measured at
\texttt{blocks.2.hook\_resid\_pre}, the residual stream immediately before
layer 2 attention.

For the activation comparison, the notebook also estimates a mean replacement
vector for each head from 1,024 calibration sequences, uses batches of 64, and
reports the MSE against the clean layer-2-pre activations.  It fits a separate
three-component PCA to each condition and reports the fraction of that
condition's activation variance captured by its first three components.  The
behavioral reference is the clean model evaluated on the same 500-sequence
draw.  Head labels below are zero-based, matching the notebook: ``head 0''
is the first layer-1 head and ``head 2'' is the third.

\subsection{When the character-count feature emerges}

Notebook 08 uses the same train/evaluation construction at each site around
layer 1, excluding BOS and newline positions. A standardized ridge probe for
cumulative character count achieves held-out $R^2=0.481$ before layer-1
attention, $0.979$ after layer-1 attention and before the MLP, $0.998$ on the
MLP branch output, and $0.997$ after the complete layer-1 block. The feature
therefore becomes strongly linearly readable at the attention update, while
the MLP mainly refines and calibrates the representation. This is evidence
about when the feature emerges, not by itself evidence that attention performs
a literal scalar addition.

The most direct result is that head 2 is functionally close to dispensable for
the newline decision in this model: zeroing it changes precision by only
$0.0039$ and recall by $0.0321$ relative to the clean condition.  Its
downstream activation MSE is also the smallest of the four single-head
ablations ($0.364743$).  Head 0 is less dispensable but still not individually
essential: its zero ablation lowers precision by $0.0527$ and recall by
$0.1063$, while retaining a newline prediction frequency of $0.1020$.
These are functional statements about the trained circuit, not claims that
the heads have identical representations: the PCA3 variance is computed
within each intervened condition and therefore does not by itself measure
closeness to the clean trajectory.

The contrast with head 1 is useful for interpreting the result.  Zeroing head
1 eliminates all newline predictions in this evaluation, while head 3 causes
a substantial recall loss.  Thus, layer-1 heads are not interchangeable
contributors to the pre-layer-2 trajectory: at least one head carries a strong
causal contribution to the newline computation, while head 2 contributes
little detectable function under this intervention.  The fact that head 2's
zero ablation changes the layer-2-pre activation at all, despite its small
behavioral effect, also leaves open the possibility that it writes redundant
or behaviorally irrelevant structure into the trajectory.

\subsection{Layer-1 head 1 carries the character-count feature}

Notebook 09 localizes the representation more specifically by probing
cumulative character count.  It uses the same 256 training and 256 evaluation
sequences at every site, excludes BOS and newline positions, and fits
standardized linear ridge probes for the count after the current token.  It
probes both each head's raw \texttt{blocks.1.attn.hook\_z} output and its
residual-stream contribution $z_hW_{O,h}$.  Head 1 is exceptional: its raw
output gives held-out count $R^2=0.975$ with MAE $2.91$, and its residual
contribution gives $R^2=0.974$ with MAE $2.96$.  The corresponding $R^2$
values for heads 0, 2, and 3 are only $0.097$, $0.141$, and $0.112$.
Within the limits of a linear probe, head 1 therefore carries nearly all of
the count information accessible from the full pre-MLP residual stream.

This is also causal.  A ridge probe trained on the clean post-layer-1
activation has held-out $R^2=0.997$ and MAE $0.99$.  Applying this fixed probe
after zero-ablating individual layer-1 heads gives $R^2=0.990$ (head 0),
$-1.287$ (head 1), $0.967$ (head 2), and $0.928$ (head 3).  The negative
$R^2$ after removing head 1 means that the clean count readout becomes worse
than a constant mean prediction; its MAE rises to $29.96$.  The intervention
therefore identifies head 1 as the dominant causal writer of the count
feature, not merely a head whose output correlates with count.

This result should be stated narrowly.  It establishes that head 1 is the
main carrier of a linearly readable cumulative-count coordinate, not yet that
it implements a literal scalar accumulator.  Head 3 causes a noticeable
degradation of the count readout without carrying much count information by
itself, suggesting a supporting boundary or geometric role.  The layer-1 MLP
then refines the head-1-produced representation before it is passed to layer
2.

\subsection{Line geometry before the layer-1 MLP}

The head-isolation results identify causal contributors, but they do not by
themselves describe the geometry that those contributors construct.  Notebook
11 analyzes that geometry at
\texttt{blocks.1.hook\_resid\_mid}, the residual stream after layer-1
attention and before the layer-1 MLP.  We generated 128 examples, identified
the contiguous ordinary-token segments between newline tokens, and retained
1,143 segments containing at least four ordinary tokens.  For each segment we
fit a separate one-dimensional PCA line to the activation vectors.  As a
held-out check, the line was fit using alternating token positions and tested
on the remaining positions.

The segments are strongly line-like.  The rank-one reconstruction $R^2$ was
$0.926$ on average (median $0.944$), and the alternating-token held-out
$R^2$ averaged $0.892$ (median $0.920$).  Thus, before the MLP, the model
usually places the tokens within a line segment near a one-dimensional line
segment in activation space.  This result is consistent with the visual
observation that tokens between two newline boundaries form a compact,
ordered trajectory rather than an unstructured cloud.

We next tested the stronger hypothesis that movement along this line is
proportional to the character length of the earlier token.  After projecting
each segment onto its fitted line, we regressed both the signed adjacent
displacement and the Euclidean distance between adjacent activations on the
preceding token's character length.  The median $R^2$ values were only
$0.068$ for signed displacement and $0.053$ for Euclidean distance.  The
corresponding median correlations were negative ($-0.206$ and $-0.137$),
despite the fact that $92.5\%$ of adjacent signed steps were positive on
average.  The trajectory therefore tends to progress in one direction, but
longer tokens do not produce proportionally larger local steps.

A joint scalar-coordinate model makes the same point.  Predicting the
coordinate from both token position and cumulative character count achieved
mean $R^2=0.979$ (median $0.986$), but token position alone already achieved
mean $R^2=0.969$ (median $0.981$).  A pooled spacing regression had correlation
$-0.108$ and $R^2=0.012$, while within-segment shuffled-length controls had
mean correlation approximately $0.001$.  These results do not show that
token length is absent from the network; they show that the layer-1
attention-to-residual transformation does not expose token length as a simple
proportional spacing rule in this pre-MLP trajectory.  The evidence instead
supports a distinction between a strong one-dimensional line geometry and a
weaker, currently unsupported character-length metric along that line.

This also qualifies the interpretation of the head-1 ablation.  Head 1 is
behaviorally indispensable and attends substantially to newline keys, but the
resulting line geometry should not yet be described as a literal token-length
counter.  The layer-1 MLP may further transform the line: zeroing its output
produced post-layer-1 activation MSE $5.91$ in the corresponding single-example
diagnostic.  The present analysis therefore localizes a robust geometric
intermediate without assigning the full counting computation to one attention
head or to a single scalar token-length coordinate.

Taken together, the current evidence supports the following construction
story.  The embedding, positional stream, and layer 0 first create a
line-conditioned state, although the specific layer-0 circuit remains to be
localized.  Layer-1 attention then retrieves newline-boundary information and
constructs the main line-progress feature.  Head 1 is especially important:
its output alone carries nearly all of the linearly readable cumulative
character-count signal, and zeroing it destroys the downstream count
representation as well as newline behavior.  Its newline-key values are also
causally relevant.  The resulting post-attention, pre-MLP residual stream organizes
tokens within each line into an approximately one-dimensional ordered
trajectory.  That trajectory is not a simple character-length metric: local
spacing is not proportional to the preceding token length.  Finally, the
layer-1 MLP makes another substantial geometric transformation, producing the
activation that enters layer 2 at
\texttt{blocks.2.hook\_resid\_pre}.  This identifies a robust intermediate
representation while leaving the exact division of labor between layer-0
components, the layer-1 OV circuit, and the layer-1 MLP as open questions.

\section{How layer 2 uses the pre-layer-2 activation}

The preceding section describes the geometry constructed by the first two
layers.  The next question is how the final attention layer reads that
geometry to decide whether the next token should be a newline.  The relevant
input is the residual stream at
\texttt{blocks.2.hook\_resid\_pre}, which is the post-layer-1 activation.
The most useful analysis so far concerns the final layer's query--key scores:
content-token queries are compared against newline-token keys, and the
resulting attention output is then used by the final MLP and unembedding.

\subsection{Which final-layer heads matter?}

Notebook 13 independently mean-ablates each attention head by replacing its
\texttt{hook\_z} output at every position with a mean vector estimated from a
separate calibration set (2,048 sequences), then evaluates newline metrics on
1,024 held-out sequences.  The unablated baseline is recall $0.9998$,
precision $0.5185$, and newline-prediction frequency $0.1029$.  Among the
layer-2 heads, mean-ablating head 1 gives recall $0.9999$, precision $0.4042$,
and frequency $0.1321$; head 3 gives recall $0.7439$, precision $0.4818$,
and frequency $0.0824$.  Thus head 1 has the largest layer-2 precision
effect in this intervention, whereas head 3 has the largest recall effect.
Zero ablation gives the same qualitative picture: layer-2 head 3 reduces
recall to $0.9226$ and precision to $0.4506$, while layer-2 head 1 leaves
recall at $0.9935$ and precision at $0.4989$.  The final decision is
therefore distributed across heads; head 3 is the clearest single head for
the boundary-scoring mechanism, but it is not the sole carrier of the
newline computation.

Notebook 07 gives the complementary descriptive result.  It averages the

decays very rapidly, while head 3 grows toward later within-line positions.
Head 2 is more irregular and has a late-position peak.  This makes the
attention pattern look like a collection of boundary- and position-sensitive
features rather than a single uniform ``attend to the newline'' operation.

\subsection{QK geometry: queries encode progress, keys encode the line}

Several notebooks study the query--key computation directly.  In Notebook
10, character-count and line-width probe directions are passed through the
next block's layer normalization and affine $W_Q/W_K$ maps.  The resulting
joint PCA is especially low-dimensional for layer-2 head 3: its first three
components explain $75.96\%$, $9.72\%$, and $6.74\%$ of the joint variance.
For head 1 the corresponding values are $64.29\%$, $15.07\%$, and
$9.02\%$.  Notebook 12 repeats the construction using actual mean residual
activations rather than probe directions.  The first three components then
explain $63.80\%$, $31.19\%$, and $4.69\%$ for head 3, and $76.33\%$,
$22.27\%$, and $1.21\%$ for head 1.  These results support a compact
low-dimensional QK interaction, but they do not by themselves identify the
coordinates as pure character count or line width.

Notebook 18 makes the relevant factorization more explicit.  For each head,
it averages the pre-final activations by characters remaining and projects
those means through the final layer's $W_Q$, while projecting the mean
newline activation through $W_K$.  A joint three-dimensional PCA explains
$97.74\%$, $99.39\%$, $98.95\%$, and $99.46\%$ of the variance for heads
0--3 respectively.  Thus, for each head, the query embeddings trace a
smooth, essentially low-dimensional path as the line is consumed, while the
newline keys form a separate reference point.  The QK dot product can then
compare the current query's position on that path with the newline-key
representation.

\subsection{A boundary-relative score in the strongest QK analysis}

Notebook 16 focuses on layer-2 head 3 and computes, for every valid
content-query/previous-newline pair, the exact scaled inner product
\[
    s_{\mathrm{NL}} = q_{\mathrm{query}}\cdot k_{\mathrm{NL}}/\sqrt{d_{\mathrm{head}}},
\]
as well as the competitor-relative margin
\[
    m = s_{\mathrm{NL}} - \operatorname{logsumexp}(s_{\mathrm{other\ keys}}).
\]
The cached attention scores agree with the explicit QK calculation to within
$7.6\times10^{-6}$, and the sigmoid of the margin agrees with the cached
softmax probability to within $2.0\times10^{-6}$.  This verifies that the
analysis is reading the actual attention computation rather than a proxy.

Across 654,139 query/newline pairs, the margin is strongly organized by
$\text{character count}-\text{line width}$.  In a boundary window, the mean
margin is $-2.523$ at offset $-10$, $-0.1215$ at $-3$, $+0.1484$ at $-2$,
$+0.6520$ at the boundary, and $+1.568$ at offset $+7$.  The corresponding
mean QK score peaks shortly before the boundary and then decreases, while
the relative margin keeps increasing because the competing keys are being
suppressed.  This is the clearest current evidence that the final attention
layer converts the pre-layer-2 trajectory into a boundary-relative newline
signal rather than merely copying a fixed newline feature.

\subsection{What information do newline keys contribute?}

Notebook 29 separates the routing pattern from the information carried by
newline values. It evaluates 2,048 fresh sequences and reports newline
precision and recall after interventions to final-layer Head 3. ``Mean
values'' replaces all newline value vectors within a sequence by their
sequence mean; ``random shuffle'' applies one seeded uniform random
permutation of those values; and ``zero values'' sets them to zero. The
attention interventions either concentrate the same total newline attention
on the previous newline, spread it uniformly over previous newlines, or
remove newline attention and renormalize the remaining keys.

The baseline has newline precision $0.5220$ and recall $0.9995$. Mean value
replacement reduces precision to $0.4759$ and recall to $0.9642$; a random
permutation reduces them to $0.4709$ and $0.9528$; and zeroing newline values
reduces them to $0.4942$ and $0.9177$. Concentrating attention on the
previous newline leaves recall at $0.9995$ but reduces precision to $0.4936$.
Spreading the same total newline attention uniformly reduces recall to
$0.9209$, while removing newline attention gives recall $0.9735$ and
precision $0.5165$. Thus newline values are not interchangeable in their
causal effect, and the distribution of attention across newline keys matters;
however, newline-key attention is only one route into a redundant final
decision and its removal does not abolish newline prediction.

Overall, the current layer-2 picture is: layer 1 and its MLP create a
low-dimensional, line-structured residual trajectory; final-layer queries
move along that trajectory as the current line is consumed; newline keys
encode the line-boundary state; and the query--key inner product, together
with competition from other causal keys, produces a boundary-relative signal
that the final readout turns into newline predictions.  The causal head
ablations caution that this computation is implemented redundantly or in
parallel across multiple heads, even though head 3 provides the most direct
and interpretable QK boundary analysis so far.

\section{Current progress and next steps}

The codebase now contains a reproducible training and evaluation pipeline,
checkpointing, token-level tests, and a collection of interpretability
notebooks.  The existing analyses examine, among other things, attention to
previous newline tokens, probes for character counts, activation trajectories,
head ablations, and the geometry of query--key interactions near the final
prediction layer.  These experiments are intended to connect behavioral
success on line breaking to specific internal representations and circuits.

The next stage of the write-up will add quantitative training curves and a
clear account of the strongest mechanistic findings.  It will also be useful
to compare models trained with fixed versus variable line lengths, and to
separate the representation of the current line's character count from other
state variables such as line position or the identity of the previous newline.
